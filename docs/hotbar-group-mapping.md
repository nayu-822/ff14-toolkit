# ホットバー Group マッピング

このプロジェクトでは、実行時に必要な最小限のホットバー group 情報だけをコードに残し、調査メモや根拠はこの文書にまとめます。

## 現在の解釈

- `1-7`: クラス
- `8-18`: クラフターとギャザラー
- `19-25`: 新生ジョブ
- `26-28`: `ACN`、`SMN`、`SCH`
- `29-42`: `ROG` / `NIN` を含む後続ジョブ
- `43`、`49`: 現時点では不明
